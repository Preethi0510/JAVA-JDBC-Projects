# Java JDBC Projects

A collection of Java console applications developed using JDBC and MySQL.

## Projects

### 1. Library Management System
- Book management
- Member registration
- Book issue and return
- Fine calculation

### 2. Employee Leave Management System
- Employee registration
- Leave application
- Leave approval and rejection
- Leave balance management

### 3. Inventory Management System
- Product management
- Stock updates
- Low-stock monitoring
- Stock history

## Technologies Used
- Java
- JDBC
- MySQL
- Eclipse IDE

## Database Setup
Create the required MySQL databases before running each project.

Configure your database connection credentials locally.
